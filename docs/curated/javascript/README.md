# JavaScript Commands For Robot + Selenium

These are **JavaScript commands** used inside the Robot keyword:

```robot
Execute Javascript    <javascript code here>
```

They are **not** Robot keywords by themselves.

- `02_localstorage.md` — localStorage read/write/clear
- `03_sessionstorage.md` — sessionStorage read/write/clear
- `04_document_and_dom.md` — document title, elements, text
- `05_window_and_scroll.md` — scroll, size, location
- `06_cookies_javascript.md` — cookie read/write via JS
- `07_alerts_and_prompts.md` — alert/confirm/prompt handling
- `08_forms_and_inputs.md` — set/get input values via JS
- `09_wait_and_conditions.md` — wait patterns with JS
- `10_common_automation_snippets.md` — useful ready-to-use snippets

# Simple API Method Examples (Robot Framework)

Live demo API used in all files:
- https://jsonplaceholder.typicode.com

Files:
- `api_get.robot`
- `api_post.robot`
- `api_put.robot`
- `api_patch.robot`
- `api_delete.robot`

Run one file:

```powershell
robot robottestcase/api_get.robot
```

Run all API files:

```powershell
robot robottestcase/api_*.robot
```
